# Laporan pembaikan dan ujian KVSkills Hub

**Penguji:** Astra · **Tarikh:** 3 November 2026

Suite asal lulus. Suite regresi menjalankan 111 semakan respons HTTP serta asersi tambahan pada kandungan, pangkalan data, SMTP simulasi dan pelayar. Ujian menggunakan MariaDB 10.4 sementara, pelayan PHP tempatan dan Chrome headless. Ujian kebenaran fail menggunakan Apache XAMPP pada port loopback berasingan. Migrasi tambahan jadual had akses turut berjaya pada pangkalan data tempatan aplikasi.

**Pengoperasian.** Pemasang kini hanya menyediakan admin awal dan tidak menulis semula kata laluan akaun contoh. Kata laluan sedia ada yang pernah menggunakan nilai contoh perlu ditukar. Untuk pemasangan lain yang telah mempunyai data, jalankan `php database/install.php --auth-limits-only` bagi menyediakan jadual had akses. Sahkan pautan diterima melalui peti masuk ujian menggunakan alamat HTTPS rasmi sebelum mengaktifkan pemulihan kepada pengguna.

**Menjalankan semula.** Gunakan pangkalan data sementara kosong bernama `kvskills_qa` pada `127.0.0.1:38493`. Tetapkan pemboleh ubah sambungan, `INITIAL_ADMIN_EMAIL` dan `INITIAL_ADMIN_PASSWORD` khusus ujian. Jalankan pemasang, `php tests/run.php` dan `node tests/uat.mjs`. Suite HTTP menggunakan dua port loopback tambahan, 38494 dan 38495. Ujian penghantaran menggunakan sokongan SMTP PHP Windows. Untuk menyertakan ujian Chrome, tetapkan `QA_BROWSER_MODULE` kepada URL modul Playwright yang dipasang.
